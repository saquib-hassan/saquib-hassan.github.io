# Saquib Hassan — Portfolio

Personal portfolio website for **Saquib Hassan** (AI / ML / Generative AI / LLM Engineer), hosted on GitHub Pages.

- Live site: https://saquib-hassan.github.io/
- Repository: https://github.com/saquib-hassan/saquib-hassan.github.io

## Tech stack

- HTML5, CSS3, vanilla JavaScript
- Google Fonts (Space Grotesk, DM Sans)

## Local development

Open `index.html` in a browser. No build step is required.

## Updating content (easy maintenance)

- **Projects**: edit the `Projects` section in `index.html`. Use status badges (`Completed`, `In Progress`, `Planned`). Only mark projects completed when supported by a public repo or verified work. Add repo/demo links, tags, and case-study text as you publish them. (Tip: for frequent updates, consider moving project data into a small JSON file and rendering it with JS later; currently content is in `index.html`.)
- **Skills**: edit the `Skills` section in `index.html`.
- **Writing topics**: edit the `Writing` section in `index.html`.
- **Resume/CV**: replace `files/Saquib_Al_Hassan_Resume.pdf` and keep the link in the About section.
- **Profile image**: update `Saquib.JPG` (or change the reference in `index.html` and OG/Twitter meta tags if needed).
- **Contact info**: update the Contact section in `index.html` (keep only verified details).

## Deployment (GitHub Pages)

This repo is served via GitHub Pages from the configured branch (typically `main`, root). Push changes to that branch; GitHub Pages will publish the site.
