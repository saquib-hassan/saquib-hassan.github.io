# Saquib Hassan — Portfolio

Personal portfolio website for **Saquib Hassan** (AI / ML / Generative AI / LLM Engineer), hosted on GitHub Pages.

- Live site: https://saquib-hassan.github.io/
- Repository: https://github.com/saquib-hassan/saquib-hassan.github.io

## Tech stack

- HTML5, CSS3, vanilla JavaScript
- Google Fonts (Space Grotesk, DM Sans)

## Local development

Open `index.html` in a browser. No build step is required.

## Updating content

- **Projects**: edit the Projects section in `index.html`. Use status badges (`Completed`, `In Progress`, `Planned`). Only mark projects completed when supported by a public repo or verified work. Add repo/demo links, tags, and case-study details as you publish them.
- **Skills**: edit the Skills section in `index.html`.
- **Writing**: edit the Writing section in `index.html` (includes links to Medium and Hashnode).
- **Resume/CV**: replace `files/Saquib_Al_Hassan_Resume.pdf` and keep the link in the About section.
- **Profile image**: update `Saquib.JPG` in the repo root (also update `og:image`/`twitter:image` in `index.html` if you change the filename/path).
- **Contact info**: update the Contact section in `index.html` (keep only verified details).

## Deployment (GitHub Pages)

Served from the configured branch (typically `main`, root). Push to that branch to publish.
